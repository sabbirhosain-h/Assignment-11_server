# 🚀 LibrisGo — Server (Backend)

## 📖 Project Overview
This is the backend server for the BookCourier library delivery management system. It provides REST APIs for authentication, book management, orders, payments, reviews, and role-based access control.

## 🌐 Live Server
https://your-server-live-url.com

## ⚙️ Core Features
- RESTful API architecture
- JWT-based route protection
- Firebase token verification
- MongoDB database integration
- Role-based authorization (User, Librarian, Admin)
- Secure CORS configuration
- Order lifecycle management
- Payment tracking
- Wishlist & reviews API

## 🛠️ Technologies Used
- Node.js
- Express.js
- MongoDB
- Firebase Admin SDK
- JWT
- CORS
- dotenv
